# BIFS619 Group 01 Project

## Overview
This repository contains the group project for BIFS619, primarily focused on bioinformatics analysis with directories for raw data, alignment, and annotation workflows.

## Structure
The repository is organized as follows:
- `00_rawdata`: Contains the initial datasets used for analysis
- `01_allignment`: Contains alignment scripts and results
- `02_annotation`: Contains annotation files and processes
- `Master Code`: Contains the main code for the project workflow

## How to Run the Master Code

### Prerequisites
- A modern web browser (as this is primarily HTML-based)
- Basic knowledge of bioinformatics principles

### Instructions
1. Clone the repository to your local machine:
   ```
   git clone https://github.com/FaithIgomodu/BIFS619_GROUP_01.git
   ```

2. Navigate to the "Master Code" directory:
   ```
   cd "BIFS619_GROUP_01/Master Code"
   ```

3. Open the HTML files in your web browser:
   - You can do this by double-clicking the HTML files or right-clicking and selecting "Open with" your preferred browser
   - Alternatively, you can use the terminal:
     ```
     open index.html  # On macOS
     # OR
     start index.html  # On Windows
     # OR
     xdg-open index.html  # On Linux
     ```

4. Follow the on-screen instructions in the HTML interface to execute the workflow
