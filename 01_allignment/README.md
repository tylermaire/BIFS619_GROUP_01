# 01_allignment

This folder contains all files and outputs related to the alignment and quality control steps of the BIFS619 group project. Key subfolders and their contents:

## Folder Structure

- `QC/`  
  Contains files from the quality control step, including pre- and post-cleaning table CSVs and other QC metrics.

- `alignment/hisat2_index/`  
  HISAT2 index files (`genome.1.ht2` – `genome.8.ht2`) used for read mapping.

- `alignment/logs/`  
  Log files and summary reports from HISAT2 alignment.

- `alignment/plots/`  
  Barplots visualizing mapping percentages and read counts.

- `alignment/tables/`  
  CSV table of alignment metrics for all processed samples.

- `alignment/bam/`  
  **BAM files are not stored in this repository due to GitHub’s file size limits.  
  Instead, download them from our Google Drive:**  
  [Google Drive - BIFS619 BAM files](https://drive.google.com/drive/folders/1KW6iuHfbfBAplelDN6l0az1ePj9p1X8c?usp=sharing)

- `code/`  
  Contains analysis scripts, code used for alignment, QC, and downstream processing.

- `test/`  
  (If present) Contains test files or sample data used for validation.

## Notes

- All file and folder names are referenced directly in analysis scripts.
- For questions or issues, please contact the repository owner or open a GitHub issue.
- See each subfolder’s README, if present, for more details.
